How this works

The NFC tag stores an HTTPS link back to this hosted file. The link includes your Instagram target. When another phone scans the tag, the page opens in the browser and immediately attempts an Android intent:// targeted at com.instagram.android. If that fails, it falls back to the exact Instagram HTTPS URL.

This does not require NFC Tasks on the scanning phone. However, Android/iOS/browser security can still require a user tap or choose the browser instead of Instagram. A web page cannot override those operating-system rules.
